PurpleAirMatterDataLoggerConstants module

Copyright 2025 carlkidcrypto, All rights reserved.

Matter Data Logger constants for PurpleAir sensors.

Maps PurpleAir sensor fields to Matter device type structures per the Connectivity Standards Alliance Matter 1.5.1 Specification.

Requires: purpleair_api >= 1.5.0a1 (includes purpleair_api.PurpleAirMatterConverter)

PurpleAirMatterDataLoggerConstants.HEALTH_PATH = '/health'

Path for the health check endpoint.

PurpleAirMatterDataLoggerConstants.MATTER_ALL_SENSORS_PATH = '/matter/sensors'

Path for the all-sensors Matter device list endpoint.

PurpleAirMatterDataLoggerConstants.MATTER_DATA_LOGGER_DEFAULT_HOST = '127.0.0.1'

Default host to bind the HTTP server to (use 127.0.0.1 to avoid exposing the API by default).

PurpleAirMatterDataLoggerConstants.MATTER_DATA_LOGGER_DEFAULT_PORT = 9855

Default HTTP server port for the Matter data logger web interface.

PurpleAirMatterDataLoggerConstants.MATTER_DATA_LOGGER_LOG_LEVEL = 'INFO'

Default log level for the Matter data logger.

PurpleAirMatterDataLoggerConstants.MATTER_SENSOR_PATH_PREFIX = '/matter/sensor'

Path prefix for individual sensor Matter device endpoint.

PurpleAirMatterDataLoggerConstants.STATION_DATA_TIME_STAMP_METRIC_NAME = 'purpleair_matter_data_timestamp'

Metric name for data_timestamp

PurpleAirMatterDataLoggerConstants.STATION_SENSOR_COUNT_METRIC_NAME = 'purpleair_matter_sensor_count'

Metric name for sensor_count
